Circuit breaker

⏻
Runs outside the AI model's control. It's plain code, not a prompt — the model cannot override it. If the daily loss limit is hit, every strategy pauses automatically and stays paused until a human manually reviews and re-arms it.
◧
Explainable, not a black box. Every stop-loss and position size is a fixed formula you can read in the source — no hidden logic.

Setup Guide

The exact path from downloading the package to a running dashboard, taken from the included README.

Install dependencies

Run the package install command to pull in Next.js, Prisma, and all required libraries.

Configure your database

Point Prisma at a database (a free-tier option works for testing) and run the included migration to create all tables.

Add your broker API keys

Enter your own broker credentials in the environment file to enable real order placement — the framework never ships with any keys of its own.

Review and adjust risk limits

Set your own max risk per trade, daily loss limit, and position caps before enabling any strategy live.

Run in paper mode first

Start with paper trading to confirm behavior matches your expectations before connecting real funds.

Go live

Switch to live mode once you're confident — the dashboard, risk layer, and circuit breaker all work identically in both modes.
